#  Roblomon

A fan-made Pokémon-style RPG that runs entirely in your browser.
No downloads, no installs — just open the HTML file and play.

## Features
-  Overworld map with buildings to explore
-  Turn-based battles with wild Roblomon and rival trainers
-  Pixel art battle animations for every move
-  Pokéballs and Great Balls to catch Roblomon
-  Items, potions and a shop
-  Mid-battle party switching
-  Quests and rewards
-  Player vs player trading system
-  Save system using browser localStorage

## How to play
1. Open `roblomon_new.html` in any modern browser
2. Create an account and pick your starter
3. Use arrow keys or WASD to move
4. Walk into tall grass to find wild Roblomon
5. Enter buildings to heal, shop, trade and battle
